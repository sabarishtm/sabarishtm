Paatu Vaathiyar for Android

Your Carnatic singing teacher, now on Android. It is not on Google Play yet, so you install it from this page. It takes about two minutes. On iPhone, get it from the App Store instead.

Download for Android
Version 1.0 · 4.5 MB · needs Android 8.0 or newer

Opened this link from WhatsApp, Instagram or Telegram? Those apps often block downloads. Tap ⋮ (or the share icon) at the top and choose Open in Chrome (or Open in browser), then tap the button above.

Before you start

  • Use the phone itself. Open this page on the Android phone you will sing with, not on a computer.
  • Check your Android version. Open Settings → About phone → Android version. It needs to be 8.0 or newer. Most phones from 2018 onwards are fine.
  • Free space. You need about 20 MB.

Step 1: Download

  1. Tap Download for Android above.
  2. Chrome may warn: “File might be harmful”. Tap Download anyway. Chrome shows this for every app that does not come from Google Play.
  3. When “Download complete” appears at the bottom, tap Open.

If you missed the pop-up, open the Files app (on Samsung, My Files), go to Downloads, and tap paatu-vaathiyar-1.0.apk.

Step 2: Allow your phone to install it

The first time, Android stops and says something like “For your security, your phone is not allowed to install unknown apps from this source.”

  1. Tap Settings in that message.
  2. Turn on Allow from this source (on some phones, Allow app installs).
  3. Press Back. You are returned to the install screen.

The permission belongs to the app that opened the file. If you opened it from Files or My Files, allow that app rather than Chrome.

If the message did not offer a Settings button, turn it on by hand. Find your phone below:

Google Pixel, Motorola, Nokia, and most other phones

Settings → Apps → Special app access → Install unknown apps → Chrome → Allow from this source

On some phones, Special app access is under Settings → Apps → ⋮ → Special access, or under Advanced.

Samsung Galaxy

Settings → Apps → ⋮ (top right) → Special access → Install unknown apps → Chrome (or Samsung Internet, or My Files) → Allow from this source

If Auto Blocker is on (Settings → Security and privacy → Auto Blocker), Samsung blocks every app that is not from a store. Turn it off, install the app, then turn it back on. The app keeps working.

Xiaomi, Redmi, POCO

Settings → Privacy protection → Special permissions → Install unknown apps → Chrome → Allow from this source

On older phones it is Settings → Additional settings → Privacy → Unknown sources. Xiaomi may also run its own security scan before installing. Wait for it to finish, then tap Continue or Install anyway.

OnePlus, OPPO, Realme

Settings → Apps → Special app access → Install unknown apps → Chrome → Allow

On OPPO and Realme you may also see a verification step. Enter your phone PIN, or tap Install anyway.

Vivo, iQOO

Settings → Security (or Privacy) → Install unknown apps → Chrome → Allow

Step 3: Install

  1. Tap Install.
  2. Google Play Protect may say it does not recognise the developer, or offer to Scan app. Either tap Scan app and wait, or tap More details → Install anyway. You do not need to turn Play Protect off.
  3. When you see “App installed”, tap Open. The app is called Paatu Vaathi on your home screen and in the app drawer.

Step 4: Turn on the microphone

Paatu Vaathiyar listens to you sing. Your voice is analysed on the phone, and nothing is recorded or sent anywhere.

  1. When you reach Find your Sa, Android asks “Allow Paatu Vaathi to record audio?”. Tap While using the app.
  2. If you tapped Don’t allow by mistake, open Settings → Apps → Paatu Vaathi → Permissions → Microphone → Allow only while using the app. If the app is not listed, tap See all apps first.
  3. Android 12 and newer also have a phone-wide microphone switch. Swipe down twice from the top of the screen and make sure the Microphone access tile is on. On Samsung it is also in Settings → Security and privacy → Privacy → Microphone access.

Step 5 (optional): Lock the door again

Once the app is installed, you can turn Allow from this source back off for Chrome, using the same path as in Step 2. Paatu Vaathiyar keeps working. Turn it on again only when you install an update.

Singing tips

  • Wired headphones or the phone speaker work best. Bluetooth earbuds add a delay, so the tanpura and the guide voice can lag behind the tala.
  • Find a quiet room. Hold the phone about an arm’s length away.
  • Set your Sa first (Me → Change Sa). If everything you sing shows as “off”, your Sa probably does not match your voice.

Updating to a new version

When there is a new version, it will be on this page. Download it and install it over the old one, the same way as above. You do not need to uninstall first, and your Sa, progress and streak are kept.

If something goes wrong

Nothing happens when I tap Download

You are probably inside WhatsApp, Instagram or another app’s built-in browser. Open the page in Chrome (⋮ → Open in Chrome) and try again.

“App not installed” or “Package conflicts with an existing package”

Free up some storage and try again. If it still fails, uninstall the old Paatu Vaathi first (press and hold the icon → Uninstall), then install again. Uninstalling resets your progress.

“There was a problem parsing the package”

The download was cut short, or your phone runs Android older than 8.0. Delete the file from Downloads, download it again on Wi-Fi, and check your Android version.

“Blocked by Play Protect” with no Install anyway button

Tap the small arrow or More details to reveal Install anyway. On Samsung, turn off Auto Blocker for a moment (see Step 2).

The app opens, but the ribbon doesn’t move when I sing

Check the microphone permission and the Microphone access tile (Step 4). Also make sure no call or other app is using the microphone, and that the phone is not on silent-only Bluetooth headphones without a mic.

I can’t find the app after installing

Look for Paatu Vaathi (the short name) in the app drawer. Swipe up from the home screen and search.
