Paatu Vaathiyar for Android

Your Carnatic singing teacher, now on Android. It is not on Google Play yet, so you install it from this page. On iPhone, get it from the App Store.

Download for Android
Version 1.0 · 4.5 MB · Android 8.0 or newer

How to install

  1. Open this page on your Android phone and tap Download for Android. If Chrome says the file might be harmful, tap Download anyway.
  2. Open the downloaded file. If your phone asks, allow your browser to install unknown apps, then go back.
  3. Tap Install. If Play Protect says it does not recognise the developer, tap More details → Install anyway. That warning appears for any app that is not from Google Play.
  4. Open Paatu Vaathi and allow the microphone when asked.

Updating: download the new version from this page and install it over the old one. You do not need to uninstall, and your progress is kept.

Help

It cannot hear me. Open Settings → Apps → Paatu Vaathi → Permissions and allow the microphone. Headphones help.
